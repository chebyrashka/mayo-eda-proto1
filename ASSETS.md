## Typography

User-supplied font-face definitions are stored in `app/mayo-fonts.css`. All interface text uses `mayo-sans`, with system sans-serif fallbacks and `font-display: swap`. Font binaries are loaded directly from the supplied URLs under https://www.mayoclinic.org/mayofonts/Fonts/mayo/; none are downloaded or redistributed in this repository. The supplied serif/display definitions are retained but not used by the interface. External font availability depends on Mayo's server and browser access.
